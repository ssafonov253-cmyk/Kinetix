СБОРКА WINDOWS EXE ЧЕРЕЗ GITHUB ACTIONS
========================================

1. Создай на GitHub новый пустой репозиторий (можно Private).
2. Распакуй содержимое этого архива на компьютере.
3. Загрузи ВСЕ файлы и папки из распакованной папки в корень репозитория.
   Важно: папка .github тоже должна попасть в репозиторий.
4. Открой репозиторий -> Actions -> Build Kinetix Windows EXE.
5. Нажми Run workflow -> Run workflow.
6. Дождись завершения. Если сборка успешна, открой запуск workflow и скачай
   Artifact с именем Kinetix-Windows-build.

В артефакте будет DDNet.exe и, если CMake создал пакет, ZIP со всеми файлами.
Сборка может завершиться ошибкой, если исходный код содержит ошибки компиляции.
Наличие workflow не означает, что EXE уже собран или проверен.
